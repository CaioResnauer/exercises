Fase 1 · do protocolo de iteração ao repositório

Uma trilha curta sobre como o Python percorre dados sem carregar tudo na memória — iteração, generators, pipelines e itertools — construída do alicerce para cima, na ordem em que os conceitos se apoiam.

Cada aula é uma página só, com atividades que você marca como concluídas. O progresso fica salvo no seu navegador, separado por aula.

Depois que um lessonNN.py é entregue, ele é corrigido e a correção vira uma página de revisão — com o conteúdo reexplicado, mais devagar, nos pontos onde houve erro.
